# Controle oficial dos cards (fonte principal)
- `controle_cards.csv`: lista de todos os cards (separador ";", UTF-8 com BOM). Colunas: id;semana;dia_sugerido;formato;area;titulo;imagens;status;publicado_em.
- `../legendas/<ID> - legenda.txt`: legenda pronta de cada card.
- `Banco de Cards - legendas.md`: todas as legendas num só arquivo.

Estes arquivos são a versão principal. A pasta "Marketing Redes Sociais" do computador do Dr. Bretane recebe uma cópia
pela tarefa de sincronização sempre que o computador estiver ligado.
